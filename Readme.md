# Telecom Customer Churn - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Telecom Customer Churn dataset to understand customer behavior and identify patterns that lead to churn.

The analysis is performed using Python with libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

## Dataset

The dataset contains customer information such as:

* Gender
* Senior Citizen
* Partner
* Dependents
* Tenure
* Internet Service
* Contract Type
* Monthly Charges
* Total Charges
* Churn

Target Variable:

* **Churn** (Yes / No)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Data Analysis Steps

1. Data loading and inspection
2. Handling missing values
3. Converting categorical variables
4. Exploratory Data Analysis
5. Data visualization

## Key Visualizations

* Churn distribution
* Gender vs Churn
* Partner vs Churn
* Contract type vs Churn
* Monthly charges distribution
* Tenure analysis

## Key Insights

* Customers with **month-to-month contracts** have higher churn rates.
* Customers **without partners** churn more frequently.
* Higher **monthly charges** are associated with increased churn.
* Fiber optic internet users show higher churn compared to DSL users.
